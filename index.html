🧠 使用指南与示例

✏️ 从灵感到交底书，只需几步

场景模拟： 假设你是一位工程师，有一个关于“智能温控花盆”的新想法，但你不知道该怎么写成专利。


  1. 输入 — 在Obsidian中打开命令面板，选择 “生成交底书-发明专利”。
  2. 回答引导提问 — 技能会问你一系列智能问题，比如“本发明的技术领域为什么领域？达到的什么效果？”等，你只需用自己的话回答即可。
  3. 一键生成草稿 — 完成后，skill 会根据你的回答自动套用专利交底书的标准格式，并在技术效果、实施例等部分给出极佳的建议文字。
  4. 查看与修改 — 生成的 Markdown 文件将自动保存在你当前笔记库的“专利草稿”文件夹中，方便编辑和二次修改。

🔎 专利申请前的“查新”必做项

使用 “专利深度解读” 功能，你可以直接粘贴一篇知网/万方上的专利号或公开号，技能会自动获取并拆解其独立权利要求，并给出竞品对比的通俗说明，帮助你摸清现有技术，避免重复申请。

💬 常见问题解答 (FAQ)

Q1. 该技能是否需要联网？

首次安装后，需要连接网络下载同步最新政策数据和内置检索映射表。在后续使用中，大部分交底书生成、解读功能可以离线运行，只有“政策嗅探”功能需要实时网络。

Q2. 我可以自己修改模板吗？

可以！所有交底书模板和问题均可通过 Obsidian 的设置面板中的“专利助手”设置页进行可视化调整，满足企业内部的独特要求。

Q3. 出现安装失败或找不到命令？

请先确定已正确安装插件并重启Obsidian，同时检查你的Obsidian版本是否在v1.2以上。若问题仍存在，欢迎去 GitHub Issues 页提交详细错误日志，通常我们会在24小时内响应。
